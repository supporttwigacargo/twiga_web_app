Taarifa za benki na kodi zimeachwa wazi kwa kuwa hazijathibitishwa.

## Kuendesha
1. npm install
2. Nakili .env.example kwenda .env.local na uweke Supabase URL na publishable key ya project inayolingana na migrations za app hii.
3. Tumia migrations zote kwa database mpya, kisha supabase/twiga-company-settings.sql kuweka taarifa za kampuni. Script ya kampuni haitabadilisha row iliyopo.
4. Tengeneza akaunti ya staff na role kupitia Supabase.
5. npm run dev

## Ukaguzi
npm run typecheck
npm run build

Backend ya backup haijaunganishwa, database haijabadilishwa, na app haijachapishwa online.
